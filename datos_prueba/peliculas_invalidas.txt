DATOS INVÁLIDOS PARA PROBAR LA VALIDACIÓN

Envía cada objeto JSON por separado a POST http://127.0.0.1:8000/movies/.
Cada objeto contiene errores en más de un campo para probar las validaciones
del modelo Movie, definido en schemas.py. Los problemas se describen bajo
cada objeto; no son parte del JSON que se debe enviar.

Película inválida 1
{
  "id": "uno",
  "title": "AB",
  "overview": "Una historia de prueba con una descripción válida.",
  "release": "2020-05-12",
  "rating": 7.0,
  "category": "Aventura",
  "earnings": 125000000.0
}
Errores: id no es un entero; title tiene menos de 3 caracteres.

Película inválida 2
{
  "id": 10,
  "title": "Fecha incorrecta",
  "overview": "Corta",
  "release": "31/12/2020",
  "rating": 6.5,
  "category": "Drama",
  "earnings": 14000000.0
}
Errores: overview tiene menos de 10 caracteres; release no usa AAAA-MM-DD.

Película inválida 3
